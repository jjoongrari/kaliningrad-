# Снять вайб

Балтийская игра о цене одной ночи в квартире. 10 случайных объявлений, реальные фотографии, бегунок, баллы и результат: **Балтийский локал**, **Охотник за халявой** или **Янтарный спонсор**.

Оформление: глубокий морской `#113F43`, песочный `#F4EFDF`, янтарный `#F6B936`, кирпичный `#A94D36`; открытка с реальным интерьером, почтовый штемпель, волны и силуэт кирпичного дома. Без внешних шрифтов, аналитики и UI-библиотек. Next.js, TypeScript, Tailwind; полностью статический фронтенд. Это отдельный репозиторий, предыдущие проекты не нужны.

## Запуск

Нужны Node.js 22.18+ и npm:

```bash
npm ci
npm run dev
```

Сайт: http://localhost:3000. Проверка и просмотр готовой статической версии:

```bash
npm run check
npm start
```

`check` запускает проверку типов, тесты правил и импорта, проверку данных, статическую сборку и HTTP-проверку всех фотографий и заголовков.

## GitHub Pages по новой ссылке

Создайте новый пустой публичный репозиторий с любым именем, например `snyat-vibe`. В распакованной папке с `package.json` выполните:

```bash
git remote add origin https://github.com/USERNAME/NEW_REPOSITORY.git
git push -u origin main
```

Замените USERNAME и NEW_REPOSITORY на свои значения. В архиве уже есть отдельная история Git и готовый коммит. Если программа распаковки не сохранила `.git`, сначала выполните:

```bash
git init -b main
git add .
git commit -m "Create Snyat Vibe"
```

На GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Затем **Actions → Publish Snyat Vibe → Run workflow**. После успешного выполнения адрес появится в Settings → Pages. Следующие push в main автоматически обновляют сайт.

Имя репозитория не зашито в код: workflow берёт basePath из `actions/configure-pages`. Для самостоятельной проверки другого подкаталога:

```bash
NEXT_PUBLIC_BASE_PATH=/your-repository npm run build
npm run test:http
npm start
```

Откройте http://localhost:3000/your-repository/. Обычная сборка без переменной снова создаст версию для корня домена. На Windows переменную окружения задайте средствами PowerShell или через настройки окружения.

## Что очищено

Источник — предоставленный файл `creative_hse_2026 - жилье клнгрд.csv`, неизменённая копия находится в `source/original-kaliningrad.csv`.

| Проверка | Результат |
| --- | --- |
| Исходные строки и поля | 50 объявлений, 23 технических столбца |
| Повторы ID / полные дубли | 0 / 0 |
| Единица цены | Одна ночь 14–15 ноября 2026 года, двое гостей |
| Подборка для игры | 49 квартир: 48 в Калининграде, 1 в Малом Исакове |
| Фотографии | 244 WebP, около 1,2 МБ суммарно; 4–5 снимков на квартиру |
| Цены игровой подборки | 1 850–4 500 ₽ за ночь; медиана 2 900 ₽ |
| Ошибка смысла столбца | Строка 32: вместо рейтинга стоит дополнительная сумма 3 500 ₽; сохранена отдельно, игровая цена из основного ценового столбца — 3 325 ₽ |
| Исключение по типу объекта | ID 4659286506: описание определяет объект как тематическое помещение, а не стандартную квартиру; запись сохранена с причиной исключения |

Удалены CSS-заголовки, рекламные описания, счётчики дополнительных фото, имена и профили хозяев, значки, видео и дублирующие превью. Неразрывные пробелы нормализованы, цены и площади приведены к числам. Из ссылок убраны трекинг и повторные параметры, сохранены даты и число гостей. По одному CSV нельзя подтвердить, что дополнительная сумма 3 500 ₽ — именно старая цена до скидки: в очищенной таблице она нейтрально названа secondary_price_rub. Цена 3 499 ₽ не округлялась; бегунок допускает любой целый рубль.

Один снимок вернул HTTP 503 и не вошёл в экспорт. В этой галерее остались четыре доступных фотографии. Исходные размеры всех успешно скачанных превью — 208×208; WebP создан без увеличения. На большом экране детализация ограничена размером исходника.

Файлы данных:

- `public/data/listings-clean.csv` — все 50 строк с 17 понятными полями, включая признак участия и причину исключения. Пустой рейтинг означает отсутствие рейтинга, а не ноль.
- `public/data/photos.csv` — отдельная таблица фотографий, связанных с объявлением через listing_id: порядок, локальный файл, исходный URL, размеры.
- `public/data/source.csv` и `template.csv` — формат для импорта в игру, 49 подходящих объявлений и локальные пути фотографий.
- `public/data/listings.json` — данные для приложения.
- `source/cleaning-report.json` — журнал очистки, SHA-256 источника и ошибки скачивания.
- `scripts/clean-data.py` — воспроизводимая обработка именно этой схемы выгрузки. Для повторной обработки нужен Python 3 и Pillow; приложению при запуске они не нужны.

Дата сбора и статус активности не указаны в исходнике. Они не придуманы: `active=null`, `availability=source_snapshot`. Игра использует снимок выгрузки; не обещает наличие квартиры в момент посещения. Явно неактивные записи (`active=false`) исключаются. Подтверждение актуальности, данное ранее для другого региона, к этой таблице не переносилось.

Цена относится к указанной ночи и двум гостям. Залог, уборка и иные сборы не включаются искусственно: их полный состав в выгрузке не установлен. Это не общая стоимость поездки и не текущая котировка площадки.

## Правила

Каждый запуск выбирает 10 разных квартир. Во время игры даты и число гостей одинаковы. Перед ответом цена скрыта в интерфейсе, после «Оценить» появляются цена, разница, баллы и ссылка на объявление с сохранёнными датами.

За квартиру: `round(100 × max(0, 1 − abs(оценка − цена) / цена))`. Ошибка на 10% — 90 баллов, на 25% — 75, на 100% и больше — 0. Максимум за игру — 1 000.

От 850 баллов — **Балтийский локал**. При меньшем счёте чаще заниженные цены дают **Охотника за халявой**, чаще завышенные — **Янтарного спонсора**. При равенстве числа завышений и занижений используется сумма знаковых относительных отклонений; при нуле — знак наибольшего относительного отклонения, а при одинаковой величине — первого по порядку.

Переплата — сумма положительных разниц `оценка − цена`, недоплата — сумма модулей отрицательных. Баланс — переплата минус недоплата. Итог относится к десяти отдельным оценкам стоимости одной ночи. Деньги не списываются.

Бегунок линейный, диапазон общий для подборки, шаг 1 ₽, начальное значение — медиана. При первом запуске демонстрируется движение; reduced motion отключает анимацию. По завершении доступны новая партия и разбор ответов.

## Обновить подборку

Для разового локального импорта нажмите «Своя таблица», загрузите CSV по шаблону и соответствующие фото. Это не отправляет файлы на сервер и не сохраняется после перезагрузки.

Для постоянного обновления положите фотографии в `public/images` и выполните:

```bash
npm run import:csv -- /path/table.csv
npm run check
```

Нужны минимум 10 квартир Калининградской области, `propertyType=apartment`, `dealType=nightly_rent`, `priceUnit=night`, `availability=source_snapshot` или `confirmed`, положительная цена, две фотографии, sourceUrl, checkIn, checkOut и guests. Даты и число гостей должны совпадать для всех записей, интервал — ровно одна ночь. `active=false` исключает запись. Поле confirmed используйте только после фактического подтверждения; неизвестная активность не превращается в true.

Цены не нужно округлять. Несколько путей в `images` разделяйте точкой с запятой. Допустимы локальные JPG, PNG, WebP и AVIF. Внешние URL фотографий, обход каталогов и исполняемые форматы не принимаются.

## Безопасность

Сборка выносит исполняемые inline-скрипты Next.js в локальные файлы. Подготовлены CSP, Referrer-Policy, X-Frame-Options, nosniff и Permissions-Policy для локального сервера, Vercel, Netlify и Nginx.

GitHub Pages не позволяет выставлять произвольные HTTP-заголовки: там действует meta-CSP, а настройки HTTP-заголовков потребуют другого хостинга. Для Netlify и Vercel конфигурация уже включена; директория публикации — `out`.

LocalStorage хранит только факт демонстрации бегунка. Результаты не уходят на сервер. Цены находятся в статических клиентских данных: прототип не защищает ответы от просмотра исходного кода.
